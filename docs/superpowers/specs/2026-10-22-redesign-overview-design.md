# 畫面重新設計：總體設計

## 背景與目的

目前的介面像一般網頁：平面卡片、開關、以 hover 為主的互動。首頁的次要入口只是三個小圖示，設定頁把性質不同的設定全疊在一起，解題演示一進去看不出在做什麼。

這次要讓 App 更有「遊戲感」，同時守住它是解謎遊戲的本質：**介面不能搶走題目的風頭**。另外要支援多種可切換的「風格」與深淺色模式，並把巡檢發現的 16 個問題一起處理。

這份文件記錄總體決定與分階段計畫；每個階段的細節另寫設計文件。

## 分支規則（使用者決定）

- 所有工作都在 `feature/redesign` 分支上進行；各階段可以先合進這個分支。
- **合回 develop 之前一定要先取得使用者明確同意**，就算審閱都通過也一樣。

## 目標

- 互動以觸控為主：按下與放開時有回饋，不依賴 hover。整體要有遊戲感但克制。
- 風格系統：玩家可以選風格，之後也可以持續新增。
- 每種風格都支援淺色、深色、跟隨系統。
- 首頁與設定頁重新配置；解題演示與遊戲回顧改用揭示提示的面板。
- 巡檢 16 項全部處理。

## 反目標（技術上能動，但這樣就算失敗）

- 換了風格之後，盤面上的資訊變得不清楚（數字、筆記、選取、提示標示）。
- 換了風格之後，比例跑掉：盤面變小、數字鍵變大。示意圖裡「實體方塊風」盤面偏小、數字列偏大，就是要避免的例子。
- 某種風格擁有自己獨立的版面或流程，導致新增畫面時要各做一套。
- 切換風格、主題色、深淺色要重開 App。
- 任何組合下文字對比不足（以 WCAG AA 為準：一般文字 4.5:1，大字 3:1）。

## 已決定事項（使用者）

| 主題 | 決定 |
|---|---|
| 風格 | 三種：極簡動態（預設，最接近現在）、實體方塊、紙本筆記；之後可再新增 |
| 風格能換什麼 | 只換外觀：材質、形狀、厚度、陰影、紋理、字型、動畫、配色。版面、按鈕位置、流程、文字、功能全部共用 |
| 主題色 | 每種風格各自有一組主題色，不強迫 6 色套用到所有風格 |
| 深淺色 | 每種風格都有淺色、深色，外加跟隨系統 |
| 預設 | 新玩家用極簡動態；老玩家更新後也停在極簡動態，保留原本選的主題色 |
| 桌面圖示 | 維持現有 6 種顏色；選了其他風格的主題色時，「App 圖示配合主題」取最接近的那一色 |
| 切換 | 風格、主題色、深淺色都即時生效 |
| 可讀性與比例 | 所有風格下，遊戲資訊都要一樣清楚；盤面寬度、數字鍵大小與兩者比例在所有風格下一致 |
| 首頁 | 「開始遊戲」是主角；統計、解題演示、技巧教學（第 4 項功能）、設定是次要但要像正式入口。「怎麼玩」不一定放首頁 |
| 設定頁 | 依性質分群，不再全部疊在一頁；開關改成更有互動感的控制項 |
| 解題演示 | 開頭說明這頁在做什麼並引導第一步。開頭就提醒「不一定能解完」，原因可能是需要更進階的技巧、輸入有誤、題目無解或多解。解不完時步驟停在解得到的地方，不另外顯示訊息。預留之後「從遊戲紀錄的失敗局開啟」的入口 |
| 解題演示與遊戲回顧 | 改用揭示提示的「盤面加下方面板」呈現 |
| 巡檢 16 項 | 全部處理 |

## 分階段計畫

每個階段各自討論細節、寫設計文件與實作計畫，依序在 `feature/redesign` 上完成。

1. **基礎**
   - 整理顏色 token，把寫死的顏色改成 token，修正對比不足（巡檢 15）。
   - 建立風格系統骨架與深淺色模式，先只實作「極簡動態」風格。
   - 建立共用的觸控回饋元件，例如按鈕、分段選擇、選項方塊。
2. **遊戲畫面**：巡檢 1–8。
   - 1–3：筆記大小與對比；盤面標示，包括選取外框、相同數字、同列欄宮；檢查衝突沒有衝突時的回饋，題目格不標紅。
   - 4–6：提示次數直接寫出剩幾次；提示面板的「取消」改「關閉」；操作按鈕加文字，並說明筆記模式與長按。
   - 7–8：完成視窗加上再玩一局、看回顧、新紀錄；放棄的安排與後果說明。
3. **首頁與設定頁**
   - 重新配置首頁入口，預留技巧教學；巡檢 9 處理首頁的難度位置。
   - 設定頁分群，加入風格、主題色、深淺色的選擇。
4. **解題演示與遊戲回顧**
   - 改用新面板；解題演示加開頭說明與範例題。
   - 巡檢 13：正式版要能載入題目，重設要能確認。巡檢 14：版面跳動。
   - 預留從失敗局開啟的入口。
5. **統計頁與更新日誌**：巡檢 10–12，以及 16（更新日誌改用玩家看得懂的用語）。
6. **另外兩種風格**：實體方塊、紙本筆記，最後檢查所有組合，包括比例與對比。

## 巡檢 16 項（2026-10-22，360×780、繁中）

1. 筆記 8px、對比 2.8:1，太小太淡。
2. 題目格、玩家格底色幾乎沒差；點題目格時那格沒有選取狀態；相同數字底色不明顯；沒有同列欄宮標示。
3. 檢查衝突沒有衝突時毫無反應但照扣提示；題目格會被標紅；只抓重複，抓不到填錯。
4. 提示次數只用圓點表示，看不懂；「第一次免費」說明不清；用完時沒有說原因。
5. 提示面板「取消」會讓人以為提示可以退回。
6. 操作按鈕只有圖示；筆記模式只差一圈外框；長按功能沒有任何說明；aria-label 幾乎沒有。
7. 完成視窗只有「回到首頁」；沒有再玩一局、看回顧、新紀錄。
8. 「放棄並離開」跟「儲存並離開」一樣醒目；沒說放棄會算一場敗場、會拉低勝率。
9. 首頁難度切換夾在「繼續遊戲」與「新遊戲」之間；繼續按鈕沒顯示難度；設定入口可點範圍小於 44px。
10. 「連續遊玩天數」實際只算有完成的日子。
11. 「清除所有紀錄」太醒目、容易誤按；最近遊戲沒有上限，不能依難度篩選；已算出的平均時間沒有顯示。
12. 統計的空白狀態看起來像真的數據。
13. 正式版解題演示沒有載入題目的方法，範例只在開發版；「重設」不用確認就清空。
14. 解題演示從輸入切到播放時版面會跳；步驟說明對比不足。
15. 多處文字對比不足；有些地方寫死白色、淺橘底、陰影顏色；深色模式需要每個主題各一組顏色。
16. 更新日誌用語太偏工程。
