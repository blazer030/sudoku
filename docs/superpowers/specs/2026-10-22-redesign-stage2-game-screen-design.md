# 重新設計 第 2 階段：遊戲畫面（巡檢 1–8）

總體設計：`docs/superpowers/specs/2026-10-22-redesign-overview-design.md`。前置：第 1 階段（token、深淺色、按壓回饋、`SegmentedControl`）。

使用者已授權直接做完 redesign。本階段的細節由我決定，全部標 ⚙︎，最後一起交給使用者檢查。

## 目的

讓遊戲畫面上的資訊一眼看得清楚：筆記、選取、相同數字、同列欄宮。讓每個操作都有明確回饋：檢查衝突、提示次數、按鈕用途、長按。結束與離開的流程清楚、不容易誤按。

## 設計

### 1. 筆記（巡檢 1）⚙︎
- 筆記字級跟著格子大小縮放，最小 10px。目前用 `clamp(8px, …, 14px)`，改成下限 10px，上限不變。
- 筆記色改用次要文字 token，並加進第 1 階段的對比測試：筆記對一般格底、題目格底、標示底，都要 ≥ 4.5:1。

### 2. 盤面標示（巡檢 2）⚙︎
- **選取格**：明顯的主色外框，2px，在格子內側。點題目格時那一格也顯示選取外框；題目格仍不能被輸入。
- **同列、同欄、同宮**：選取格所在的列、欄、宮加上很淡的底色，與「相同數字」區分。
  - 新增遊戲設定「標示同列、欄、宮」，預設開啟。設定頁的入口在第 3 階段；這階段先加資料欄位與預設值。
- **相同數字**：底色加深到能和一般格子區分，跟題目格底的對比 ≥ 1.25:1，必須看得出差別。筆記裡的相同數字照現有的 `highlightedNote` 樣式。
- **題目格與玩家格**：題目格用不同的底色 token，加上較粗的字重；玩家格維持主色字。底色差異要看得出來（同上 ≥ 1.25:1）。
- 優先順序由高到低：錯誤 → 選取 → 相同數字 → 同列欄宮 → 題目格。每一層都有自己的 token，深淺色都要定義。

### 3. 檢查衝突（巡檢 3）⚙︎
- 沒有衝突時顯示 toast：「沒有發現重複的數字」。照樣算一次提示，因為這也是資訊。
- 題目格不再被標成紅色，只標玩家填的格子。
- 選單上的說明改成「找出同列、欄、宮裡重複的數字」，讓玩家知道它不檢查答案對錯。

### 4. 提示次數（巡檢 4）⚙︎
- 提示選單直接寫「本局還剩 N 次提示」，取代原本的三個圓點。
- 免費說明改成「每局第一次提示免費，不計入統計」，只在本局還沒用過提示時顯示。
- 用完時，選項變灰並說明「本局的提示已用完（每局 4 次）」。

### 5. 提示面板用詞（巡檢 5）⚙︎
- 提示模式兩種畫面的「取消」都改成「關閉」，en "Close"。
- 面板不另外顯示已扣次數，提示選單已經寫了剩餘次數。

### 6. 操作按鈕與長按說明（巡檢 6）⚙︎
- **控制列**：復原、筆記、提示，以及數字鍵旁的擦除，都在圖示下加小字標籤，例如「筆記」，並補上 `aria-label`。
- **筆記模式**：筆記鈕的標籤改成「筆記 開」，用主色實心狀態表示開啟。數字鍵上的數字改成較小、靠上的樣式，讓人一看就知道現在輸入的是筆記。
- **長按說明**：第一次選定數字時跳一次提示：「長按格子可以直接切換筆記（筆記模式下則是填入）」。只顯示一次，用設定欄位 `seenLongPressTip` 記錄。
- **aria-label**：盤面格子「第 r 列第 c 欄，空白／5／筆記 1 3」；數字鍵「填入 5，還剩 2 個」。

### 7. 完成視窗（巡檢 7）⚙︎
- 按鈕：主要是「再玩一局」（同難度開新局）；次要是「看這局回顧」，打開剛完成這局的遊戲回顧；最後是「回到首頁」。
- **破紀錄**：完成時間比這個難度原本的最佳時間短，或這是第一場，顯示「新紀錄！」標記。「第一場」也算新紀錄 ⚙︎。
- 難度不再用 32px 大字和時間並排，改成標題下的小標籤；資訊欄保留時間與提示次數。

### 8. 離開與新遊戲的對話框（巡檢 8）⚙︎
- **離開對話框**：
  - 主要按鈕「儲存並離開」；
  - 次要的文字按鈕「放棄這局」，不再是紅色大按鈕；
  - 說明「放棄會記為一場未完成，會影響勝率」。
- **新遊戲確認框**：顯示要放棄的那一局（難度、已用時間），並寫同樣的後果說明。主要按鈕是「繼續原本那局」，次要是「放棄並開新局」 ⚙︎。

## 非目標

- 不改提示模式的流程。
- 首頁、設定頁的版面在第 3 階段。
- 「怎麼玩」說明頁不在 redesign 範圍，那是另一個待辦功能。

## 測試重點

- 筆記字級下限；筆記色加進對比測試。
- 選取外框出現在題目格；同列欄宮標示在設定開與關時的行為；相同數字與題目格的 token 對比 ≥ 1.25:1。
- 檢查衝突：沒有衝突時有 toast；題目格不標紅。
- 提示選單：顯示剩餘次數、免費說明的顯示條件、用完時的說明。
- 提示面板的按鈕文字是「關閉」。
- 按鈕標籤與 aria-label；長按說明只出現一次。
- 完成視窗三個按鈕的行為；新紀錄標記，包括第一場和平手不算新紀錄的情況。
- 離開與新遊戲對話框的主次按鈕和說明文字。
- 瀏覽器實測：360×780，中英文、淺深色。
