# 多語系（繁體中文 + 英文）實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App 介面支援英文與繁體中文，預設跟隨系統語言、可在設定頁切換且立即生效；並以 2.1.0 準備發版。

**Architecture:** 用 vue-i18n（Composition API 模式）管理所有介面文字。由純函式 `resolveLocale` 依設定與系統語言決定語言，`startLocaleSync` 監看設定與 `languagechange` 事件，並寫入 `i18n.global.locale` 與 `<html lang>`。語言偏好存在既有的 `sudoku-settings`。Android 桌面名稱用 `values-zh-rTW`／`values-zh-rHK` 資源檔處理。

**Tech Stack:** Vue 3.5、vue-i18n 11、Pinia 3、Vitest + @vue/test-utils（jsdom）、Tailwind v4、Capacitor 8 Android。

**Spec:** `docs/superpowers/specs/2026-10-21-i18n-zh-hant-design.md`（術語表、日期格式、不翻譯清單都以 spec 為準）

## Global Constraints

- 語言代碼只有 `en` 與 `zh-Hant`。設定欄位 `language` 的值是 `"system" | "en" | "zh-Hant"`，預設 `"system"`，存在 `localStorage` key `sudoku-settings`。
- 中文用語依 spec 術語表。格子位置一律寫「第 {row} 列第 {column} 欄」：row 是「列」、column 是「欄」。
- 中文日期：「今天 15:05」「昨天 09:12」「10/21 15:05」，24 小時制、小時補零、不顯示年份。英文維持現在的輸出。
- 語言選項中「English」與「繁體中文」永遠以該語言本身顯示；「跟隨系統／System」跟著目前語言翻譯。
- 翻譯後的文字不得進入 Analytics 參數、`data-testid`、存檔或統計資料。這些地方只能用 id。
- Walkthrough 測試題目的標籤（Singles／Medium／Hard）、價格 `priceText`、`console.*` 訊息、隱私權政策都不翻譯。
- 測試環境固定為 `en`，既有的英文斷言不改。每個中文斷言測完都要把語言切回 `en`（由 setup 的 `afterEach` 統一處理）。
- vue-i18n 訊息裡不可直接寫 `@`、`{`、`}`、`|`。需要時用字面插值，例如 `{'@'}`；複數用 `|` 分隔除外。
- 依專案規範：
  - TDD，每次綠燈就 commit。
  - 結構性與行為性變更分開 commit。
  - commit 訊息用英文 Conventional Commits，加 emoji 前綴，不加 Co-Authored-By。
  - commit 前 `npx vitest run`、`npm run lint`、`npx vue-tsc --noEmit` 全過。
  - 程式碼註解用英文。

## Review Focus

1. **系統語言的邊界值**：`zh-Hans-TW`、`zh-CN`、單獨的 `zh` 要顯示英文；`zh-Hant-HK`、`zh-MO` 要顯示中文；`navigator.languages` 為空時要顯示英文。測試放在 Task 2。
2. **只算一次、不會跟著切換的文字**：`GameHeader` 的難度、`Settings` 的開關陣列、`PuzzleLoader` 的預設訊息。切換語言後必須立即更新。測試分別放在 Task 5、6、7。
3. **2.0.0 留下的舊設定**：沒有 `language` 欄位時要視為 `"system"`，其他設定值保留。測試放在 Task 3。
4. **手動選了語言後系統語言又改變**：偏好是 `en` 或 `zh-Hant` 時，`languagechange` 不能覆蓋使用者的選擇。測試放在 Task 4。
5. **日期邊界**：昨天 23:59 要顯示「昨天 23:59」，不能變成日期；09:05 要補零；跨年的日期不顯示年份。測試放在 Task 10。
