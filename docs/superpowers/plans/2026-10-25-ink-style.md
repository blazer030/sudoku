> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a sixth visual style, `ink` (「水墨和紙」 / "Ink & Washi"): light only, one fixed vermilion palette, Yuji Boku / Noto Serif TC / EB Garamond type, washi pages, a brush-line board, ink-bleed digits, its own app icon and its own loading, group and celebration moments.

**Tech Stack:** Vue 3 + TS + Tailwind v4, Vitest, PostCSS sheet tests (`styleSheetRules.ts`), `subset-font`, `tsx` generator scripts, `sharp`, Capacitor Android launcher aliases.

## Review Focus

1. **Safari / iOS (WebKit) shows the brush lines.** The grid mask must be set both as `-webkit-mask-image` and `mask-image`, and the cell borders turn transparent only inside `@supports ((mask-image: url("")) or (-webkit-mask-image: url("")))`, so an engine without masks keeps plain lines. *Sheet test in Task 5.*
2. **Erasing by undo, by stepping back in Game Review, or in the Walkthrough.** The ghost shows the digit that left (not empty, not the new one), and `leaving` still settles, so `.value-leave` never sticks. *BoardCell tests in Task 4 and a sheet test in Task 7.*
3. **A brushed title holding a character Yuji Boku lacks** (for example 「產」, or a new dialog title). It falls to LXGW WenKai TC, never tofu, and the listed brush strings are fully covered. *bundledFonts test in Task 3.*
4. **A cold start with ink saved while the appearance setting is dark.** First paint is light (no `dark` class) with theme-color `#B3261E`; going ink → minimal brings dark back, since ink never writes `appearance`. *noFlashScript and settings store tests in Task 1.*
5. **One entry completing a row and a box, then another completion within a second.** Both strokes draw (the box 80ms after the row), a new effect replaces the old one, and the digits stay above the brush. *Overlay test and z-order sheet test in Task 9.*
